      Building kits are groups of objects you saved (e.g. a camp with torches). They work in every map and project: double-click or "Place" puts one at the mouse cursor or the view centre.
        New NPCs for the mod. Save, then place them in a map with "Add game object" (NPC list) and export.
          Texts by quest stage
          For quest mods (World Waypoints quests): from the given quest stage on, the NPC says this text instead.
            Click = preview · double-click = place in the view centre · P = place at the mouse cursor · drag the preview to turn it
            Scatter the model
            Places many copies of the preview model around the view centre (button) or the mouse cursor (Shift+P), e.g. plants and rocks.
            Recolour the model
            A copy of the model in the preview with new textures; the original stays.
            Import a 3D model
            OBJ or glTF (.glb) mesh, becomes a new game model (data/hd/env/model/custom/).

            Controls

            Left click: select · Shift+click: add to/remove from the selection · drag with the left mouse button: box selection · Esc: deselect
            Right mouse: orbit · middle mouse: pan · wheel: zoom
            Game objects (from the DS1, used by the game): red cones = NPCs/monsters (line = walking path), turquoise cubes = objects. Select, drag, change the type and delete them like other objects.
            Collision: choose a tool, then paint tiles (10×10 units) with left click/drag. Red = not walkable, blue = blocks only line of sight, yellow border = changed by you. "Collision under object" links the blocked area to the object: it moves along and disappears when the object is deleted.

            Combine two mods
            Both mods must be exported (in the game's mods folder). The merged mod is written as a new folder; the two stay as they are.
